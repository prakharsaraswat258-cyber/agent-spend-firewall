What Pitstop never keeps

It sits between your agent and the provider, so it sees every call. It keeps only what it needs to count money.

  • Your API key passes through to the provider and is never written down.
  • Prompts and code are forwarded, not stored. The ledger holds model, tokens, cost, time and tool names.
  • It listens on 127.0.0.1 only, and its control API refuses requests from web pages.
  • An Anthropic key only ever goes to Anthropic, and an OpenAI key only to OpenAI.
  • The whole thing is open source under Apache-2.0, so you can read every line.

Fair questions

Which agents does it work with?

Anything that takes a base URL for Anthropic or OpenAI-style APIs: Claude Code with an API key, Codex CLI, Aider, Cline and your own SDK agents. Start them with pitstop run -- <command>.

Does it see my code or keys?

Keys pass through to the provider and are never written to disk. Prompts and code are never stored. The ledger keeps metadata only: tokens, cost, model, time and tool names.

What if nobody answers the card?

After 9 minutes the run stops and your work is saved to a WIP branch. Pitstop never continues on its own.

How good is the forecast?

Remaining cost is steps left times the average cost per step so far, adjusted for growing context. It is labelled low confidence until 3 steps are done, and every forecast is scored against what really happened.

Is it for ChatGPT or Claude.ai plans?

No. Flat monthly plans have no per-call bill to protect, and a local proxy can't sit inside those apps. The same goes for Claude Code on a Pro or Max subscription.

What happens if the proxy crashes?

Agent calls fail rather than slip past your budget. Restart it with pitstop serve and carry on with pitstop resume.

What does an unknown model cost?

Pitstop blocks the call with a clear message until the model is in the price table. A wrong price would be a bug in the one thing you trust it for.
